# MediaPipe Background Removal

A collection of two background removal applications built using Google's MediaPipe Selfie Segmentation. Each application explores a different approach to removing backgrounds from visual media.

## Applications

### 1. Live Background Remover

A real-time background removal application using a live camera feed.

**Technologies:**
- Next.js
- React
- JavaScript
- MediaPipe Selfie Segmentation
- MediaPipe Camera Utils
- Tailwind CSS

[View application documentation](./live-background-remover/README.md)

### 2. Photo Background Remover

A photo background removal application that allows users to upload images for processing.

**Technologies:**
- React
- TypeScript
- Vite
- MediaPipe Selfie Segmentation
- Three.js

[View application documentation](./photo-background-remover/README.md)

## Getting Started

Each application is maintained independently and has its own dependencies and development server.

To get started, navigate into the application you want to run and follow its individual installation instructions.

## Purpose

This repository brings together two separate projects exploring real-time and static image background removal using MediaPipe.
